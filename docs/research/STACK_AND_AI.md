# Stack, maps and language research

All links accessed 2026-09-14. Model claims below describe capabilities, not Komşu accuracy.

- [FastAPI WebSockets](https://fastapi.tiangolo.com/advanced/websockets/): dependency-supported sockets; in-memory sample connection manager has process-lifetime limitations. **Decision:** durable event table with replay cursor, tenant filtering and reauthentication; bounded polling initially, broker fanout after measured need.
- [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/): client renderer. **Decision:** independent style/GeoJSON layers; no tile outage should remove list/manual workflows. Empty base map is explicit until a licensed municipal/offline tile pack is configured.
- [Nominatim policy](https://operations.osmfoundation.org/policies/nominatim/): public instance maximum 1 request/s per application, identifying agent/caching, no personal/confidential data and no heavy automated usage. **Decision:** never default to public endpoint for incoming disaster reports; explicit self-hosted or contracted provider with redaction/minimisation and bounded requests. Policies differ for self-hosting.
- [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/): no public raster bulk/offline downloads, attribution required, no SLA. **Decision:** self-host or offline-authorised provider, provider URI configurable, provenance and attribution in layer metadata.
- [PostGIS ST_DWithin](https://postgis.net/docs/ST_DWithin.html): geography distances are metres; spatial index aware. **Decision:** WGS84 geography + GiST; never calculate distance in degrees as metres.
- [pgvector](https://github.com/pgvector/pgvector): exact and approximate search; filtered ANN can reduce recall and cross-tenant shared indexes affect recall. **Decision:** initially tenant-scoped exact candidate search, then partitioned HNSW after recall measurement; no global vector candidate response.
- [PostgreSQL RLS](https://www.postgresql.org/docs/current/ddl-rowsecurity.html): owners/superusers can bypass row policies. **Decision:** runtime non-owner without BYPASSRLS, FORCE RLS and transaction-local tenant context; tests use real runtime role.
- [BAAI bge-m3 model card](https://huggingface.co/BAAI/bge-m3): 1024-dimensional multilingual embeddings, MIT; dense/sparse/multi-vector options. **Decision:** local optional dense encoder behind typed port; recorded model revision. Embedding alone never merges cases. Joint geography/time/entity gates, human confirmation and split history. Lexical baseline is explicitly not semantic bge-m3.
- [Whisper](https://github.com/openai/whisper) and [official whisper-tiny model](https://huggingface.co/openai/whisper-tiny/tree/main): pinned Apache-2.0 local transcription candidate. **Decision:** bounded approved-root PCM input, checksum verification and silence rejection implemented as an isolated adapter. Decoder sandboxing, durable encrypted audio lifecycle, Greek/noisy human fixtures and hallucination tests remain required before ingestion is connected. Missing weights or transcription error yields manual review, never invented text.
- [Zemberek](https://github.com/ahmetaa/zemberek-nlp): Turkish normalization/morphology/NER modules; slow maintenance and no included NER model noted. **Decision:** evaluate morphology aid; no claim of a ready trained address extractor.
- [spaCy Greek models](https://spacy.io/models/el): news-domain Greek entity pipelines. **Decision:** compare to multilingual transformer on noisy modern Greek addresses; news NER is not validated rescue geolocation.
- [OPUS-MT TR→EN](https://huggingface.co/Helsinki-NLP/opus-mt-tr-en/tree/main), [EN→Turkic](https://huggingface.co/Helsinki-NLP/opus-mt-en-trk/tree/main), [EL→EN tiny](https://huggingface.co/Helsinki-NLP/opus-mt_tiny_ell-eng/tree/main), [EN→EL](https://huggingface.co/Helsinki-NLP/opus-mt-en-el/tree/main): active pinned routes are Apache-2.0 Marian models. **Decision:** local-only optional pack with immutable revisions/checksums; EN pivot is explicit. Authored diagnostics found dropped names, numerals and negation, so outputs remain annotations requiring source review. Provider absence means unavailable, never source text falsely labelled translation.
- [OpenTelemetry](https://opentelemetry.io/docs/what-is-opentelemetry/): traces, metrics, logs instrumentation framework. **Decision:** PII-free low-cardinality metrics first, OTLP collector integration with redaction and bounded export queues next.

## Model selection/evaluation

Compare deterministic recall-oriented rules, multilingual transformer fine-tuning and LightGBM on frozen embeddings/metadata (PDF alternatives). Gold labels require bilingual annotators and incident-level splits. Synthetic templates are regression fixtures, never a generalisation benchmark. Time to triage includes queue delay; report unresolved locations separately. Record precision/recall/F1/FNR per TR/EL/EN; duplicate pair precision/recall; median/p95 location error only on resolved items plus unresolved fraction; translation human adequacy/critical-error rate. Confidence in baseline is an uncalibrated heuristic, displayed as such. Calibrate trained model with held-out data before thresholds become operational policy.
